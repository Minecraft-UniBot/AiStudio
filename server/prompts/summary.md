# 结果翻译任务

扩展编码与审查完成后，请用**通俗中文**总结（普通用户不熟悉代码，避免专业术语）：

## 输出结构

1. **功能**：这个扩展能做什么（2-3 句，面向非技术用户）
2. **复用情况**：如果复用了市场/GitHub 已有扩展，说明复用了什么、新增了什么（没有则省略）
3. **配置方式**：如果需要配置，说明在哪里配置、有哪些选项（含默认值）
4. **使用方式**：如何触发（指令示例 / API 调用方式）
5. **注意事项**：使用前提、已知限制（如有）

## 约束

- 不展示代码、文件路径或 Diff（这些在技术详情中可见）
- 如果存在配置项，逐项说明名称、含义和默认值
- 指令示例使用用户能直接复制的格式
- 内容必须基于实际实现，不得虚构功能或配置项；不确定的地方如实说明

# 编码规范摘要

编写扩展代码时遵守（完整细节见 `UniBot/AGENT.md`）：

- 命名：变量/函数 `snake_case`、常量 `UPPER_SNAKE`、类 `PascalCase`；**禁止自造缩写**（`msg`、`btn`、`srv` 均不允许），仅允许 `id`、`url`、`api`、`http` 等业界公认缩写
- 扩展 ID、目录名、清单 `extension.id` 三者完全一致（PascalCase，含大小写）
- 入口 `__init__.py` 顶部创建**唯一** `extension` 实例，能力模块在实例创建后导入（`noqa: E402,F401`）
- 指令类继承 `Command`，API 服务继承 `Service`，均用 `@extension.register_xxx` 装饰器登记
- 配置用 Pydantic `BaseModel` 作为 `config_model`；`extension.config.value` 读取校验后的配置
- 异步优先：网络/IO 用 async，禁止 `asyncio.run`；方法签名带类型注解
- 错误处理：不吞异常，用户可见错误信息用中文、通俗
- 日志用 `extension.logger`，不用 `print`
- 在 `tests/` 下编写 pytest 测试；需要 `Scripts.Extensions` 时用真实 import（测试由 UniBot 校验流水线执行）
